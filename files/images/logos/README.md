# Logos for the lobby and newsroom tiles

Drop logo images here and the tiles pick them up automatically — no code
changes needed. If no file exists for a group, its tile shows a colored
monogram instead.

Naming:
- Lobbies: the org code from `files/csvs/lobbyist_list.csv`, uppercase —
  e.g. `SC.png`, `TRIBES.png`
- Newspapers: the outlet name lowercased, spaces → underscores —
  e.g. `fresno_bee.png`

PNG with transparent background works best; roughly square, at least
200×200px.
