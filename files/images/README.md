# Images

- `lobbyist_logos/` — member-org logos for the Lobbyists tiles. Which
  files belong to which group is set in the `Logos` column of
  `files/csvs/lobbyist_list.csv` (";"-separated). One logo fills the
  tile; several show as a cluster; blank = colored monogram.
- `newspaper_logos/` — one logo per outlet, named in the `Logo` column
  of `files/csvs/journalist_list.csv`.
- PNG or JPG both work; roughly square crops look best.
